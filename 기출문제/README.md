## 실행

저장소를 전체 내려받아 루트에서 실행하거나 Jupyter의 시작 위치를 회차 폴더로 설정합니다. 기존 5개 노트북은 현재 회차 폴더, 신규 17개는 루트 또는 현재 회차 폴더에서 실행할 수 있습니다. 노트북만 분리하면 data/공통/src가 없어 실행되지 않습니다.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r 기출문제/requirements-py312.txt
python -m pip install notebook
jupyter notebook
# 실제 셀 실행 및 출처·스키마·출력·파일 검증
python tools/exams/audit_package.py --execute
```

Python3.7 호환 안내는 requirements-py37.txt에 있습니다. 실제 이번 묶음 전체 실행은 3.12.14에서 했으며 3.7은 코드 구문 확인, 분석 모듈은 별도 CI 런타임 확인입니다.

원 CSV 중 1MiB 이상은 **lossless .csv.gz**로 보관하고 기존 load()가 자동으로 읽습니다. 검증결과.json은 압축 해제 바이트 SHA256까지 기록합니다. 원본 raw 값을 수정하거나 표본으로 줄이지 않았습니다. 추가 합성 데이터 44개는 복원연습_데이터명세.json에서 출처·시드·행 수를 구분합니다.

## 자료와 가정

- 기존 15/17/20/22/23회: 사용자 DataManim 첨부 및 연결 Kaggle 배포 자료. 데이터_출처.json, 원본/ 보존. 17회 ARIMA/ARMA 모두 선형임을 설명하고 실제 비선형 예시 별도 추가. 20회 누락 시간 격자 및 lag 누출 방지. 22회 소수 불량수는 정식 p관리도 판정을 유보합니다.
- 모의 1~4회: 질문 markdown은 원문 명세에 보존하고 현재 질문은 상황형으로 재구성, 빠진 표·CSV/TXT를 합성 예시로 보완. 원 풀이 해설의 통계 해석·전처리 누출·확률 ROC 오류는 새 풀이에서 수정합니다.
- 추가 18/19/21/24/25/26/28회 및22회 보충: 자료가 알려주는 출제 주제에 맞춘 **복원 연습**, 미제공 조건·표본·수치는 명시 보완. 기존17/20/23과 중복인 부분은 새 세트를 만들지 않습니다.
- 한국어 텍스트는 합성 사전의 명시 POS로만 실행하며 일반 형태소 분석기를 대체하지 않습니다. 원본 문서가 확보되면 Komoran 등으로 교체합니다.
- 학습 점수·CV 최고점·보류 점수를 구분합니다. 모든 모델의 지표가 개선됐다고 단정하지 않습니다. 합성 자료의 유의성·추천·분류 결과를 실제 현장 결론으로 사용하지 않습니다.
