# 응용 모의 제5회 | 중고차 가격과 반품 위험 자료 안내

도메인 용어를 익힌 뒤 통계·모형 분석에 들어가기 위한 안내입니다. 원시 자료를 해석하는 사전이며 분석 결과나 정답을 뜻하지 않습니다.

## 1. 회귀 설계와 조건별 개선

**상황을 이해하기**

중고차 거래 가격 점수는 학습용 연속 지표이며 반품은 판매 후 거래가 취소된 사건입니다.

**관측 단위와 판단 목적**

회귀 한 행은 독립 거래, 분류 한 행은 별도의 반품 위험 관측입니다. 특이 거래의 영향력을 검토하되 가격이 극단적이라는 이유만으로 오류 처리하지 않습니다.

**변수 사전**

| 열 | 의미·역할 |
| --- | --- |
| `id` | 관측 식별자; 예측 입력에서 제외 |
| `target` | 거래 가격 점수; 예측할 반응 |
| `mileage` | 누적 주행거리의 편차 지수; 원 측정값/표본 표준화 아님 |
| `age` | 경과 연수의 편차 지수; 원 측정값/표본 표준화 아님 |
| `engine` | 엔진 규모의 편차 지수; 원 측정값/표본 표준화 아님 |
| `maintenance` | 정비 상태의 편차 지수; 원 측정값/표본 표준화 아님 |

## 2. 이진 사건 예측과 샘플링

**상황을 이해하기**

중고차 거래 가격 점수는 학습용 연속 지표이며 반품은 판매 후 거래가 취소된 사건입니다.

**관측 단위와 판단 목적**

한 행은 회귀와 별도로 생성한 독립 사건 관측입니다. 실제 사건을 놓치는 경우와 잘못 경보하는 경우의 비용을 구분합니다.

**변수 사전**

| 열 | 의미·역할 |
| --- | --- |
| `id` | 관측 식별자 |
| `target` | 1=반품 발생, 0=해당 사건 없음 |
| `c1` | 사건 전에 측정한 가상 연속 위험 신호 1 |
| `c2` | 사건 전에 측정한 가상 연속 위험 신호 2 |
| `c3` | 사건 전에 측정한 가상 연속 위험 신호 3 |
| `c4` | 사건 전에 측정한 가상 연속 위험 신호 4 |

## 3. 미래 수요와 시간순 검증

**상황을 이해하기**

중고차 거래 가격 점수는 학습용 연속 지표이며 반품은 판매 후 거래가 취소된 사건입니다.

**관측 단위와 판단 목적**

한 행은 하루입니다. 앞 두 자료와 결합하지 않는 별도의 140일 합성 시계열입니다. 앞으로 7일의 값을 예측하고 단순 기준 예측과 같은 날짜에서 비교합니다.

**변수 사전**

| 열 | 의미·역할 |
| --- | --- |
| `date` | 중복 없는 등간격 날짜 |
| `target` | 일별 수요/사용량의 학습용 연속 지표; 회귀·분류 target과 별개 |
