# 응용 모의 제9회 | 고객센터 문의 횟수와 이탈 해설

독자 기준: 분석 전공 지식을 전제로 하되 도메인 배경은 아래에서 설명합니다. 수치는 실행 결과를 읽어 표시한 값이며 상세 정밀값은 실행결과의 JSON과 노트북 출력에 있습니다.

## 1. 회귀 설계와 조건별 개선

**상황을 이해하기**

문의 횟수는 같은 하루 동안 고객센터에 접수된 건수입니다. 이탈은 고객이 이용을 중단한 사건입니다.

**관측 단위와 판단 목적**

회귀 한 행은 동일 노출의 하루, 분류 한 행은 별도 고객 사건 관측입니다. 회귀 행은 이 연습에서 독립으로 취급합니다. 정수 횟수의 평균·분산 관계와 이탈 검출을 구분합니다. 횟수 자료라고 자동으로 시계열 모형이 되는 것은 아닙니다.

**변수 사전**

| 열 | 의미·역할 |
| --- | --- |
| `id` | 관측 식별자; 예측 입력에서 제외 |
| `target` | 일별 문의 횟수; 예측할 반응 |
| `users` | 사용자 규모의 편차 지수; 원 측정값/표본 표준화 아님 |
| `release_change` | 서비스 변경 정도의 편차 지수; 원 측정값/표본 표준화 아님 |
| `usage` | 이용 강도의 편차 지수; 원 측정값/표본 표준화 아님 |
| `complexity` | 처리 복잡도의 편차 지수; 원 측정값/표본 표준화 아님 |

### 1-1

**수행 과제**

2. 지정 분할의 원행 위치를 남기고 전체 자료 대치나 식별자 입력이 왜 부적절한지 설명하시오.

**풀이 근거와 순서**

**풀이 근거와 순서**

원단위 CV R² 최대를 선택하며 후보별 clone은 각 학습 폴드에서 모든 처리를 새로 적합한다. 기준 대비 진단과 점수를 함께 보고 test로 모델을 바꾸지 않는다. 동일 노출의 횟수와 평균=분산 조건을 점검한다. 과산포·과도한0을 검토하며 서로 다른 노출에는 알려진 log exposure가 필요하다. pseudo R²와 원 단위 보류 R²는 별개다.

### 1-6

**수행 과제**

1. 선택 이후에만 기준/선택 모형을 동일 최종평가 행으로 평가하여 R²·RMSE·MAE와 R² 차이를 보고하시오.
2. 진단 전후 또는 대안 분포의 적절한 잔차·분산·영향도 근거를 해석하고, 개선이 없거나 가정 위반이 남아도 그대로 보고하시오.
3. 동일 노출의 횟수와 평균=분산 조건을 점검한다.
4. 과산포·과도한0을 검토하며 서로 다른 노출에는 알려진 log exposure가 필요하다.
5. pseudo R²와 원 단위 보류 R²는 별개다.

**풀이 근거와 순서**

같은 보류 원행에서 기준/선택 점수를 계산하고 ΔR²=선택-기준을 그대로 보고한다. 개선이나 모든 가정 만족을 보장하지 않는다. 동일 노출의 횟수와 평균=분산 조건을 점검한다. 과산포·과도한0을 검토하며 서로 다른 노출에는 알려진 log exposure가 필요하다. pseudo R²와 원 단위 보류 R²는 별개다.
