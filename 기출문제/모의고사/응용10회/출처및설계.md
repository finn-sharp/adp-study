# 출처·가정·독립 생성 범위

요청한 회귀·분류·시계열·샘플링·튜닝 절차를 반복 적용하는 창작 종합 모의10회입니다. 공식 기출 원문을 재현하거나 실제 기업의 측정·고객 자료를 사용한 것이 아닙니다. 기존1~5회·생존 모의와 독립적으로 관리합니다. 공문서형 서식과 상황형 가설·해석 계약을 유지합니다.

원리·가정의 기술 근거:

- [statsmodels OLS와 회귀 진단](https://www.statsmodels.org/stable/diagnostic.html)
- [statsmodels GLM](https://www.statsmodels.org/stable/glm.html), [Logit](https://www.statsmodels.org/stable/generated/statsmodels.discrete.discrete_model.Logit.html)
- [sklearn 모델 탐색](https://scikit-learn.org/stable/modules/grid_search.html)
- [imbalanced-learn 누출 방지](https://imbalanced-learn.org/stable/common_pitfalls.html)
- [Optuna](https://optuna.readthedocs.io/en/stable/reference/generated/optuna.study.Study.html)
- [statsmodels ARIMA](https://www.statsmodels.org/stable/generated/statsmodels.tsa.arima.model.ARIMA.html)

모든 자료는 `RandomState(20270000+회차)`로 한 번 생성하고 유리한 p값·선택 모형·ΔR²가 나오도록 시드를 재선택하지 않습니다. `tools/exams/applied_mock_data.py`에 정확한 생성식을 보존합니다. 회귀240행·분류360행·시간140일의 별도 자료를 각 회차에 제공합니다. 분할과 후보는 실행설정.json에 사전 지정합니다. 같은 열 이름이라도 다른 대문항의 관측을 결합하지 않습니다.

회귀 조건은 중복 Feature, lognormal 양수 오차, 제곱 평균함수, 부하 의존 이분산, 영향 관측5개, AR(0.75)오차, 지수 평균, Gamma(shape6) 양수 연속량, Poisson 횟수, 연속 S자 성장입니다. 세부 생성 원리는 출제자/해설용이며 수험자가 참 모형을 미리 안다고 가정하지 않습니다. 입력 결측은 반응 생성 후 독립적으로8개를 넣었습니다.

분류는 사건 확률 expit(-1.5+1.1c1-0.65c2+...)로 생성하며 짝수 회차에는 c3 제곱 효과가 있습니다. 첫 선택 Feature의 제곱항 검정 하나만으로 모든 logit 사양을 증명할 수 없는 상황입니다. 클래스 개수·사건률을 고정 결과로 강제하지 않습니다. 원 학습 분포의 비벌점 GLM 설명과 보완된 표본의 L2 예측모형은 별개입니다.

시간 자료는 일별 추세·AR 오차 및 지정 회차의 주기7 변동을 가진 합성 원단위 계열입니다. 별도 외생변수·미래 실제값을 예측 입력으로 제공하지 않습니다. 마지막7일을 봉인하고 직전14일의 두 rolling 구간에서 차수를 선택합니다. 간단한 후보 공간이므로 모형 오사양과 naive보다 나쁜 결과도 그대로 보고합니다.

유의수준5%는 개별 탐색 진단입니다. 수많은 진단/후진 선택/변환 선택 후의 p값을 family-wise 보정되거나 선택 편향이 없는 검정으로 표시하지 않습니다. 비기각은 가정의 증명이 아닙니다. Cook 영향값은 기본 검토용이고5회차에서 명시한 삭제 후보만 학습 폴드에서 수행합니다. 기준과 후보는 동일 보류 원행에서 비교합니다.
