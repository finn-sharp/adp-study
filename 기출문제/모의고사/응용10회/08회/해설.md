# 응용 모의 제8회 | 보험 지급액과 청구 위험 해설

독자 기준: 분석 전공 지식을 전제로 하되 도메인 배경은 아래에서 설명합니다. 수치는 실행 결과를 읽어 표시한 값이며 상세 정밀값은 실행결과의 JSON과 노트북 출력에 있습니다.

## 1. 회귀 설계와 조건별 개선

**상황을 이해하기**

보험 지급액은 청구가 인정되어 지급된 금액입니다. 청구 이상은 검토가 필요한 사건 표시이며 실제 부정행위 확정이 아닙니다.

**관측 단위와 판단 목적**

회귀 한 행은 지급액이 양수인 청구 건, 분류 한 행은 별도 이상 검토 관측입니다. 양수 금액의 평균·분산 구조와 검토 대상을 놓치는 비용을 각각 판단합니다.

**변수 사전**

| 열 | 의미·역할 |
| --- | --- |
| `id` | 관측 식별자; 예측 입력에서 제외 |
| `target` | 지급액(백만원); 예측할 반응 |
| `severity` | 사고 심각도의 편차 지수; 원 측정값/표본 표준화 아님 |
| `delay` | 접수 지연의 편차 지수; 원 측정값/표본 표준화 아님 |
| `exposure` | 사전 사고 노출 지표(관측시간 offset 아님)의 편차 지수; 원 측정값/표본 표준화 아님 |
| `complexity` | 처리 복잡도의 편차 지수; 원 측정값/표본 표준화 아님 |

### 1-1

**수행 과제**

1. 관측 단위·목표 척도·예측 시점과 입력의 역할을 정리하고 결측·분포·공선성 후보를 탐색하시오.
2. 지정 분할의 원행 위치를 남기고 전체 자료 대치나 식별자 입력이 왜 부적절한지 설명하시오.

**풀이 근거와 순서**

원행 위치를 먼저 봉인하고 결측 대치·스케일·선택은 Pipeline.fit 안에 둔다. id는 의미 없는 식별자이며 test는 최종 보고만 한다.

3. 특히 양수 연속 반응의 Gamma log-mean 후보의 적용 조건과 처리 단위를 설명하시오.

**풀이 근거와 순서**

원단위 CV R² 최대를 선택하며 후보별 clone은 각 학습 폴드에서 모든 처리를 새로 적합한다. 기준 대비 진단과 점수를 함께 보고 test로 모델을 바꾸지 않는다. log 평균 링크와 Var(Y|X)=phi mu²를 확인한다. Pearson/deviance 잔차·분산 사양을 사용하며 반응 또는 잔차 정규성·보통 R²를 분포 조건으로 강요하지 않는다. 예측 비교는 원단위 R²다.

### 1-6

**수행 과제**

1. 선택 이후에만 기준/선택 모형을 동일 최종평가 행으로 평가하여 R²·RMSE·MAE와 R² 차이를 보고하시오.
2. 진단 전후 또는 대안 분포의 적절한 잔차·분산·영향도 근거를 해석하고, 개선이 없거나 가정 위반이 남아도 그대로 보고하시오.
3. log 평균 링크와 Var(Y|X)=phi mu²를 확인한다.
4. Pearson/deviance 잔차·분산 사양을 사용하며 반응 또는 잔차 정규성·보통 R²를 분포 조건으로 강요하지 않는다.
5. 예측 비교는 원단위 R²다.

**풀이 근거와 순서**

같은 보류 원행에서 기준/선택 점수를 계산하고 ΔR²=선택-기준을 그대로 보고한다. 개선이나 모든 가정 만족을 보장하지 않는다. log 평균 링크와 Var(Y|X)=phi mu²를 확인한다. Pearson/deviance 잔차·분산 사양을 사용하며 반응 또는 잔차 정규성·보통 R²를 분포 조건으로 강요하지 않는다. 예측 비교는 원단위 R²다.
