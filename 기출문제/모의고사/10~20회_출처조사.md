# 실제 ADP 실기10~20회 조사와 신규 모의16~20회

확인일: 2026-10-23. 아래의 **실제 시험 회차**와 이 저장소의 **모의 회차**는 서로 다릅니다. 공개 응시 후기에서 확인한 주제만 사용했고, 후기 문장을 시험 원문으로 옮기지 않았습니다. 공식 원문·원 데이터·공식 정답을 확보한 것으로 표시하지 않습니다. 새 모의는 각12문항·100점·권장240분이며 조건·숫자·자료·채점 관점·평가 설계는 독립 창작입니다.

17회 후기 간에는 배점·지표 명칭·상위 국가 수 등이 다릅니다. 18회도 분류 평가와 군집 평가의 설명이 혼재하고, 20회의 ‘예측한계선’·집계 수준·회귀 ‘정확도’는 작성자 스스로 불명확함을 밝힙니다. 이 모의에서는 그 불명확한 문장을 정답으로 확정하지 않고 평가 목적·관측 단위·RMSE/MAE/R²·구간 정의를 새로 명시했습니다. 실제 배점을 복원한 것으로 표시하지 않습니다.

## 데이터·재현·해설의 기준

자료는 `RandomState(20281000+모의회차)`로 한 번 생성합니다. 유리한 p값·선택 모형·점수를 찾기 위한 재시딩은 하지 않습니다. 생성식은 `tools/exams/researched_mock_data.py`, 전체 지문과 출처별 연결은 `tools/exams/researched_mock_specs.py` 및 각 회차 `문항명세.json`에 있습니다.

- 모든 전처리·sampling·튜닝은 해당 학습/CV 안에 있습니다. 최종 평가는 후보·임계값·구간 폭을 정하는 데 사용하지 않습니다.
- 시간1-step은 전날 실제값이 매일 공개되는 운영입니다. 여러 날 동시 예측 성능으로 표시하지 않습니다. calibration도 후보 선택에서 제외하며 시간 의존성이 있는 경험 구간의 보장을 주장하지 않습니다.
- 영어 명사/형용사는 제공 어휘 사전의 품사입니다. 일반 형태소 분석기나 문맥 부정 처리의 구현·성능을 뜻하지 않습니다.
- 1~5 순서척도를 등간 점수로 근사해 공분산·Pearson 상관·PCA·평균 비교에 사용한다는 조건이 있다. alpha·PCA·Welch는 서로 다른 질문이며 신뢰도·타당도·단일차원·인과를 혼동하지 않습니다. 음수 정정치, 빈 거래, 미일치 문서, 군집 라벨과 결합 분모도 명시합니다.
- `공통/researched_core.py`는 상태·순서·수치 기록, `researched_prediction.py`는 예측, `researched_temporal.py`는 시간/집계, `researched_descriptive.py`는 문서/거래/설문 조합입니다. OLS·진단·Feature·평가·ARIMA/SARIMA·Apriori·PCA·Welch·Q-Q 등은 기존 `src`를 호출합니다. 사전 토큰화·alpha 공식·히트맵 배치 등은 과제별 코드이며 등록 모듈266개를 늘린 것으로 집계하지 않습니다.

실행 환경은 공통 requirements의 고정 버전입니다. 방법 설명의 공식 기술 근거는 [시간 분할](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html), [PCA](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html), [Welch t](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_ind.html), [Ljung-Box의 model_df](https://www.statsmodels.org/stable/generated/statsmodels.stats.diagnostic.acorr_ljungbox.html)에 있습니다.

```bash
python tools/exams/build_researched_mocks.py
python tools/exams/run_researched_mocks.py
python tools/exams/audit_researched_mocks.py
python tools/exams/audit_mock_readability.py
python tools/exams/build_catalog.py
python tools/exams/audit_catalog.py
```

문제 생성 후 풀이를 실행해야 실제 수치 해설이 갱신됩니다. [독립 검증 결과](공통/조사모의_검증결과.json)는 지문·배점·출처·고정 CSV와 직접 OLS/지표/순위 AUC/Welch/alpha·집계·경계 검산을 기록합니다. 새 세트는 이전 기출 묶음을 덮어쓰지 않습니다.
