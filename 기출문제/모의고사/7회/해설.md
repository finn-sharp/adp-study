독자 기준: 분석 전공 지식을 전제로 하되 도메인 배경은 아래에서 설명합니다. 수치는 실행 결과를 읽어 표시한 값이며 상세 정밀값은 실행결과의 JSON과 노트북 출력에 있습니다.

## 1. 회귀 설계와 조건별 개선

**상황을 이해하기**

배송비는 화물을 운송하는 비용이며, 파손은 운송 중 물품이 손상된 사건입니다.

**관측 단위와 판단 목적**

회귀 한 행은 배송 건, 분류 한 행은 별도의 배송 위험 관측입니다. 큰 비용의 예측 오차와 파손 누락 위험을 각각 평가합니다.

**변수 사전**

| 열 | 의미·역할 |
| --- | --- |
| `id` | 관측 식별자; 예측 입력에서 제외 |
| `target` | 배송비(천원); 예측할 반응 |
| `weight` | 화물 무게의 편차 지수; 원 측정값/표본 표준화 아님 |
| `distance` | 배송 거리의 편차 지수; 원 측정값/표본 표준화 아님 |
| `volume` | 화물 부피의 편차 지수; 원 측정값/표본 표준화 아님 |
| `handling` | 취급 난이도의 편차 지수; 원 측정값/표본 표준화 아님 |

### 1-1

2. 지정 분할의 원행 위치를 남기고 전체 자료 대치나 식별자 입력이 왜 부적절한지 설명하시오.

**풀이 근거와 순서**
