# 모의고사 1회 자료 안내

도메인 용어를 익힌 뒤 통계·모형 분석에 들어가기 위한 안내입니다. 원시 자료를 해석하는 사전이며 분석 결과나 정답을 뜻하지 않습니다.

## 1. 추첨 기록의 동시 출현

**상황을 이해하기**

한 행은 1~12에서 6개 번호를 고른 합성 추첨입니다. 실제 로또 제도를 재현하지 않습니다.

**관측 단위와 판단 목적**

거래 한 건처럼 한 행을 항목집합으로 보고 동시 출현을 요약합니다. 등장 순서는 의미가 없습니다. 지문에서 요구한 비교·예측·요약의 결과와 불확실성을 상황에 맞게 보고합니다.

**변수 사전**

| 열 | 의미·역할 |
| --- | --- |
| `lotto.csv / n1` | 추첨에 포함된 번호 1 |
| `lotto.csv / n2` | 포함 번호 2 |
| `lotto.csv / n3` | 포함 번호 3 |
| `lotto.csv / n4` | 포함 번호 4 |
| `lotto.csv / n5` | 포함 번호 5 |
| `lotto.csv / n6` | 포함 번호 6 |

## 2. 선수 시장가치 설명

**상황을 이해하기**

선수의 포지션은 경기 역할이며 시장가치는 거래 대상으로서의 평가 지표입니다.

**관측 단위와 판단 목적**

한 행은 독립 선수 표본입니다. 평균 차이나 연관성이 이적 가격의 인과 원인이라는 뜻은 아닙니다. 지문에서 요구한 비교·예측·요약의 결과와 불확실성을 상황에 맞게 보고합니다.

**변수 사전**

| 열 | 의미·역할 |
| --- | --- |
| `FIFA.csv / Position` | 경기 역할: 공격(FW/ST/CF/LW/RW), 중원(MD/CM/CDM), 수비(Defender/CB/LB/RB), 골키퍼(GK) |
| `FIFA.csv / Preferred_Foot` | 주로 사용하는 발: Left=왼발, Right=오른발 |
| `FIFA.csv / Age` | 선수 나이 |
| `FIFA.csv / Overall` | 종합 능력 지표 |
| `FIFA.csv / Wage` | 임금 지표(통화·기간 미제공) |
| `FIFA.csv / Height` | 키: 피트·인치 문자열(예: 6'2 = 6피트 2인치). 환산은 지문 규칙 |
| `FIFA.csv / Weight_lb` | 몸무게: 파운드 |
| `FIFA.csv / Value` | 시장가치 지표(통화 미제공) |

## 3. 영화 리뷰 요약

**상황을 이해하기**

문서에서 관심 단어의 빈도와 날짜별 관심을 요약합니다.

**관측 단위와 판단 목적**

한 행은 문서 한 건입니다. 품사는 제공된 학습 사전의 표시에 한정됩니다. 지문에서 요구한 비교·예측·요약의 결과와 불확실성을 상황에 맞게 보고합니다.

**변수 사전**

| 열 | 의미·역할 |
| --- | --- |
| `reviews.csv / date` | 문서 작성 날짜 |
| `reviews.csv / text` | 분석할 문서 내용 |
| `lexicon.csv / word` | 학습용 품사 사전에 등록된 단어 |
| `lexicon.csv / pos` | Noun=명사, Adjective=형용사 |
