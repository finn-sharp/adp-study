# 생존분석 통계 모의

**3개 대문항·14개 소문항·연습 배점 60점·권장 90분**의 독립 확장 통계 파트다. 머신러닝 파트는 포함하지 않는다. 기존 모의 1~4회나 복원 기출을 덮어쓰지 않으며, 기존 22묶음의 문항 수와는 별도로 관리한다. 지문·CSV·수치는 모두 새로 만든 창작 학습 자료다.

| 구성 | 학습 내용 | 출제 근거의 수준 |
| --- | --- | --- |
| 1. 공급 장비 수명 | 우측 중도절단, 위험집합, 생존함수, 누적 고장확률, 조건부 확률, 중앙수명, 두 집단 비교 | 28회 응시자 후기에서 기본 유형 확인 |
| 2. 서비스 유지기간 | 세 집단 비교, 전체/쌍별 가설, Holm 보정, 24개월 제한평균생존시간 | 기본 유형을 확장한 창작 응용 |
| 3. 설비 고장 요인 | Cox 회귀, 보정 위험비·신뢰구간·Wald 검정, 개별 생존확률, 잔차 기반 PH 진단 | 공식 기술 문서를 참고한 확장 연습; 기출 출제 확인 아님 |

문제에는 방법명을 직접 주지 않고 상황·관측 설계·가정을 제시한다. 추정 문제에는 가설검정을 요구하지 않는다. 검정 문제의 풀이는 방법 선택과 가정 → H0/H1 → 실제 계산값 → 기각 여부 → 업무 맥락의 결론을 따른다. 비기각은 동일성이나 가정의 증명이 아니다.

## 사용

- `생존분석_통계_문제지.pdf`: 응시자용 문제만 포함한다.
- `생존분석_통계_해설.ipynb`: 문항별 설명과 실제 실행된 출력·그림을 포함한다. 노트북의 폴더를 작업 위치로 실행한다.
- `실행결과/답안수치.json`: 실제 추정값과 검정 가설·원/보정 p-value·기각 여부·결론. 설명형 문항의 해설은 노트북에 있다.
- `문항명세.json`: PDF와 해설의 지문·배점 대응.
- `출처조사.md`: 웹 근거·상이한 회상·확장 범위.
- `검증결과.json`: 위험집합 수계산, 독립 로그순위 계산, PDF 지문·경계·출력 검사 결과.

## 자료 설계

| CSV | 행 수 | 관측 단위·변수 | 생성 방식 |
| --- | ---: | --- | --- |
| supplier.csv | 32 | 장비 id, 공급사 group, time(개월), event(고장=1) | 손으로 설계한 동시 고장/절단·미도달 중앙수명 사례 |
| subscription.csv | 240 | 가입자 id, 정책 group, time(개월), event(해지=1) | 집단별 지수 수명, 독립 Uniform(12,36) 종료 |
| equipment.csv | 360 | 장비 id, time, event, temperature10, load10, new_part | 지수 기준위험 0.035, 로그 위험 계수 0.55·0.35·-0.7, 독립 Uniform(24,48) 종료 |

난수는 `RandomState(20261019)`를 사용하며 그룹·공변량·수명·종료를 생성한다. 기록 기간은 min(실제 사건시간, 종료시간)이고 사건 지표는 사건시간≤종료시간이다. 사후에 p값을 맞추기 위해 표본을 재선택하지 않는다. 1번의 동시 사건/절단은 둘 다 직전 위험집합에 넣고 사건 반영 후 제거한다. B 공급사 중앙수명은 관찰 중 미도달이며 JSON에서는 `null`이다. 생존확률은 우연속 계단값을 사용한다.

PH 진단은 rank 변환·세 변수 Holm 보정을 사전 고정한다. 계수별 Wald p-value는 개별 5% 탐색 검정이며 동시 추론으로 주장하지 않는다. RMST는 같은 24개월까지의 기술통계로만 비교한다. 반복사건·경쟁위험·지연진입·정보성 절단은 이 자료의 범위 밖이다. 모든 실제 업무 결론은 합성 자료 연습에만 적용된다.
