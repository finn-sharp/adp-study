# 생존분석 통계 모의 자료 안내

도메인 용어를 익힌 뒤 통계·모형 분석에 들어가기 위한 안내입니다. 원시 자료를 해석하는 사전이며 분석 결과나 정답을 뜻하지 않습니다.

## 1. 공급 장비의 보증기간 검토

**상황을 이해하기**

생존은 사람이 살아 있다는 뜻에 한정되지 않고 장비가 아직 최초 고장을 겪지 않았다는 뜻입니다.

**관측 단위와 판단 목적**

중도절단은 관찰을 끝낼 때까지 고장이 없었다는 정보이며 실제 고장시간이 아닙니다. 위험집합은 그 직전까지 고장 없이 관찰 중인 장비입니다. 지문에서 요구한 비교·예측·요약의 결과와 불확실성을 상황에 맞게 보고합니다.

**변수 사전**

| 열 | 의미·역할 |
| --- | --- |
| `supplier.csv / id` | 장비 식별자 |
| `supplier.csv / group` | 장비 공급사 A/B |
| `supplier.csv / time` | 설치일부터 고장/관찰 종료까지 개월 |
| `supplier.csv / event` | 1=최초 고장, 0=관찰 종료 때까지 무고장 |

## 2. 서비스 정책별 유지기간 평가

**상황을 이해하기**

가입 후 최초 해지까지의 유지기간을 정책별로 비교합니다.

**관측 단위와 판단 목적**

해지를 사건으로 정의하므로 생존확률은 미해지 확률입니다. 정책은 무작위 배정이 아니어서 정책 효과를 곧바로 인과로 해석하지 않습니다. 지문에서 요구한 비교·예측·요약의 결과와 불확실성을 상황에 맞게 보고합니다.

**변수 사전**

| 열 | 의미·역할 |
| --- | --- |
| `subscription.csv / id` | 가입자 식별자 |
| `subscription.csv / group` | 가입 시점 정책 A/B/C |
| `subscription.csv / time` | 가입일부터 해지/관찰 종료까지 개월 |
| `subscription.csv / event` | 1=최초 해지, 0=관찰 종료 때까지 미해지 |

## 3. 설비 상태를 반영한 고장 위험 평가

**상황을 이해하기**

환경 조건을 함께 고려하며 부품 종류와 최초 고장의 관계를 설명합니다.

**관측 단위와 판단 목적**

위험비는 같은 시점에 아직 고장 나지 않은 장비 사이의 순간 위험 비율입니다. 누적 고장확률의 비와 다릅니다. 지문에서 요구한 비교·예측·요약의 결과와 불확실성을 상황에 맞게 보고합니다.

**변수 사전**

| 열 | 의미·역할 |
| --- | --- |
| `equipment.csv / id` | 장비 식별자 |
| `equipment.csv / time` | 설치일부터 고장/종료까지 개월 |
| `equipment.csv / event` | 1=최초 고장, 0=관찰 종료 |
| `equipment.csv / temperature10` | (온도-60)/10: 1 증가가 10도 증가 |
| `equipment.csv / load10` | (부하율-70)/10: 1 증가가 10%p 증가 |
| `equipment.csv / new_part` | 신규 부품=1, 기존 부품=0 |
