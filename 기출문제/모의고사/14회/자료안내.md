# 모의고사 14회 | 고객센터 문의 횟수와 이탈 자료 안내

도메인 용어를 익힌 뒤 통계·모형 분석에 들어가기 위한 안내입니다. 원시 자료를 해석하는 사전이며 분석 결과나 정답을 뜻하지 않습니다.

## 1. 회귀 설계와 조건별 개선

**상황을 이해하기**

문의 횟수는 같은 하루 동안 고객센터에 접수된 건수입니다. 이탈은 고객이 이용을 중단한 사건입니다.

**관측 단위와 판단 목적**

회귀 한 행은 동일 노출의 하루, 분류 한 행은 별도 고객 사건 관측입니다. 회귀 행은 이 연습에서 독립으로 취급합니다. 정수 횟수의 평균·분산 관계와 이탈 검출을 구분합니다. 횟수 자료라고 자동으로 시계열 모형이 되는 것은 아닙니다.

**변수 사전**

| 열 | 의미·역할 |
| --- | --- |
| `id` | 관측 식별자; 예측 입력에서 제외 |
| `target` | 일별 문의 횟수; 예측할 반응 |
| `users` | 사용자 규모의 편차 지수; 원 측정값/표본 표준화 아님 |
| `release_change` | 서비스 변경 정도의 편차 지수; 원 측정값/표본 표준화 아님 |
| `usage` | 이용 강도의 편차 지수; 원 측정값/표본 표준화 아님 |
| `complexity` | 처리 복잡도의 편차 지수; 원 측정값/표본 표준화 아님 |

## 2. 이진 사건 예측과 샘플링

**상황을 이해하기**

문의 횟수는 같은 하루 동안 고객센터에 접수된 건수입니다. 이탈은 고객이 이용을 중단한 사건입니다.

**관측 단위와 판단 목적**

한 행은 회귀와 별도로 생성한 독립 사건 관측입니다. 실제 사건을 놓치는 경우와 잘못 경보하는 경우의 비용을 구분합니다.

**변수 사전**

| 열 | 의미·역할 |
| --- | --- |
| `id` | 관측 식별자 |
| `target` | 1=고객 이탈, 0=해당 사건 없음 |
| `c1` | 사건 전에 측정한 가상 연속 위험 신호 1 |
| `c2` | 사건 전에 측정한 가상 연속 위험 신호 2 |
| `c3` | 사건 전에 측정한 가상 연속 위험 신호 3 |
| `c4` | 사건 전에 측정한 가상 연속 위험 신호 4 |

## 3. 미래 수요와 시간순 검증

**상황을 이해하기**

문의 횟수는 같은 하루 동안 고객센터에 접수된 건수입니다. 이탈은 고객이 이용을 중단한 사건입니다.

**관측 단위와 판단 목적**

한 행은 하루입니다. 앞 두 자료와 결합하지 않는 별도의 140일 합성 시계열입니다. 앞으로 7일의 값을 예측하고 단순 기준 예측과 같은 날짜에서 비교합니다.

**변수 사전**

| 열 | 의미·역할 |
| --- | --- |
| `date` | 중복 없는 등간격 날짜 |
| `target` | 일별 수요/사용량의 학습용 연속 지표; 회귀·분류 target과 별개 |
