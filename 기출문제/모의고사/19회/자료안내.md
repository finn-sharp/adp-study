# 모의고사 19회 | 설문 척도·국가별 추이·교호작용 회귀 자료 안내

도메인 용어를 익힌 뒤 통계·모형 분석에 들어가기 위한 안내입니다. 원시 자료를 해석하는 사전이며 분석 결과나 정답을 뜻하지 않습니다.

## 1. 설문 방향·신뢰도·차원 요약

**상황을 이해하기**

설문팀은 부정 문항의 방향을 맞추고 척도의 일관성과 집단 차이를 탐색한다.

**관측 단위와 판단 목적**

한 행은 독립 응답자이며 두 집단의 처치는 관측되지 않았다. 신뢰도·차원·집단 차이가 서로 다른 질문임을 설명한다.

**변수 사전**

| 열 | 의미·역할 |
| --- | --- |
| `id` | 응답 식별자 |
| `group` | 관측 집단 A/B; 무작위 배정 아님 |
| `q1` | 서비스 편의 긍정 문항(1~5) |
| `q2` | 서비스 불편 부정 문항; 역변환 |
| `q3` | 이용 만족 긍정 문항(1~5) |
| `q4` | 이용 불만 부정 문항; 역변환 |

## 2. 가상 국가 누적 자료와 예측

**상황을 이해하기**

가상 누적 신고 자료를 차분하고 인구 규모를 고려한 비교표를 만든다.

**관측 단위와 판단 목적**

한 행은 국가·날짜별 합계이며 개별 환자가 아니다. 정정치·분모·단위와 임의 위험점수의 한계를 구분한다.

**변수 사전**

| 열 | 의미·역할 |
| --- | --- |
| `country` | 실제 국가와 무관한 A~D |
| `date` | 등간격 일자 |
| `population` | 가상 인구; 분모 |
| `cases` | 수정 포함 누적 확진 건수 |
| `deaths` | 누적 사망 건수 |

## 3. 주택 교호작용과 예측

**상황을 이해하기**

관측의 조건과 결과 관계를 설명하고 새 관측의 결과를 예측한다.

**관측 단위와 판단 목적**

한 행은 서로 독립인 관측이다. x1=면적 편차지수, x2=노후도 편차지수, x3=접근 점수, target=주택가격(천만원). 추론의 조건과 예측 성능을 구분해 보고한다.

**변수 사전**

| 열 | 의미·역할 |
| --- | --- |
| `id` | 독립 관측 식별자; 입력 제외 |
| `x1` | 면적 편차지수 |
| `x2` | 노후도 편차지수 |
| `x3` | 접근 점수 |
| `group` | 관측 집단 범주 A/B; 처치 아님 |
| `target` | 주택가격(천만원) |
