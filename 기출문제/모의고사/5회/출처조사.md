# 출처·조건 확인·창작 범위

사용자 지정 참고:

1. https://m.blog.naver.com/plasticcode/221517148322
2. https://m.blog.naver.com/2theright/223883377283

웹 검색 도구는 네이버 본문 접근에 실패했고 브라우저는 사이트 정책으로 차단했습니다. 우회 접근하지 않았습니다. 첫 번째 글 본문은 확인하지 못했으므로 그 구현을 재현했다고 주장하지 않습니다. 두 번째 글은 사용자가 제공한 세로 화면 이미지에서 제목 「생산 최적화를 해보자(공부용) feat.유전알고리즘」, 2025-05-30 표기, 생산 조건 및 결과를 직접 확인했습니다.

확인한 설계 상수: 연1년·일8시간·주5일·연50주, 세 직렬 공정, 한 대 처리분3/2/4, 구매비5000/7000/4000만원, 운영비1000/1200/800만원, 목표50000개, 공정별 정수1~10대. 실제 라인능력은 각 공정능력의 최솟값입니다. 화면 결과의2/1/2대·29800만원·60000개를 새 Python 계산과 독립 전수열거로 대조했습니다.

서두의 '5000원 예산'은 일반적인 최적화 설명의 예시이지 본 생산 시나리오의 예산 조건이 아닙니다. 문제지에서 이를 구분합니다. 새29,000만원 예산,70,000/90,000개 목표, 시드 반복, 품질예측·처리시간 추론은 창작 확장입니다. 원문의 MATLAB 코드·설명·그림을 복사하지 않고 입력 설계 상수와 주제만 참고했습니다.

quality.csv는300독립배치를 가정한 합성 특성·비선형 수율, temperature18개 결측입니다. cycle_times.csv는 세 공정×old/new×30독립 정규 표본의 합성 자료이며 실제 측정이나 원문의 실험자료가 아닙니다. 음수 처리시간·지정하지 않은 불량률을 생성하지 않습니다. 표본을 유리한 p값에 맞춰 재선택하지 않습니다. 단측 검사공정 비교,여섯 정규성 진단의Holm,세 평균 상한의Bonferroni는 사전 고정했습니다.

기존 상황형 설계·공문서형 렌더러와 임베딩 나눔고딕을 재사용합니다. 원자료 확인과 확장 범위는 이 문서에 보존하고 최적해·유의성의 해석 한계는 풀이에 기록합니다.
