# 모의고사 제5회: 생산 의사결정

기존 공문서형 문제지·상황형 지문과 동일한 **14문항·100점·권장180분** 종합 모의입니다. 머신러닝40점, 생산 최적화40점, 처리시간 표본 검정20점입니다. 공식 기출·공식 배점·공식 정답이 아닙니다. 기존 1~4회 및 생존분석 통계 모의를 덮어쓰지 않습니다.

- `모의고사_5회_문제지.pdf`: 응시자용 문제만 포함합니다.
- `모의고사_5회_풀이.ipynb`: 동일 지문·선택 근거·실제 실행 출력·그림.
- `분석코드.py`: 노트북과 같은 순서의 독립 실행 코드.
- `해설.md`: 방법·가정·가설·상황 결론. 실제 수치는 노트북과 수치 답안 참조.
- `data/`: 품질300배치, 공정설계3행, 처리시간180표본 CSV.
- `실행결과/답안수치.json`, `실행검증.json`, `검증결과.json`: 실제 답안·실행·독립 대조 기록.
- `문항명세.json`, `출처조사.md`: 지문·배점·확인 범위와 창작 보완 구분.

학습/최종평가 분리·CV 내 전처리, 정수 설비 배분과 병목, 제약 실행가능성, GA 시드 반복과 전수해 대조, 예산 불가능성, 독립 표본의 평균 감소와 다중 평균 상한을 연결합니다. 최적화에는 가설검정을 억지로 붙이지 않으며 평균 신뢰상한을 개별 제품 예측상한이나 라인 가동 신뢰도로 해석하지 않습니다.

```bash
# Python 3.12 별도 환경, 저장소 루트에서
python -m pip install -r 기출문제/모의고사/5회/requirements-py312.txt
python tools/exams/execute_notebooks.py 기출문제/모의고사/5회/모의고사_5회_풀이.ipynb

# 분석코드는 해당 파일 폴더에서 실행
(cd 기출문제/모의고사/5회 && python 분석코드.py)
# 재생성 후 실행 출력은 위 명령으로 다시 생성

```

Python3.7 문법은 유지하지만 모의고사 전체 수치 실행은 Python3.12 환경입니다. 분석 모듈의3.7/3.12 CI와 콘텐츠 실행 환경을 구분합니다. 정적 공정 상수는 사용자 제공 글 화면에서 확인했으며 CSV의 품질·처리시간은 시드20261023으로 만든 합성 자료입니다. 합성 결과를 실제 공장 개선 효과로 해석하지 않습니다.
