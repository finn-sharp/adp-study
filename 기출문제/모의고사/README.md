# 모의고사 안내

- 기존 종합 모의: `1회/` ~ `4회/`의 문제지와 풀이 노트북.
- [생존분석 통계 파트](생존분석_통계/README.md): 웹 출제 후기를 참고한 창작 확장 모의 14문항(60점·권장 90분). 문제지 PDF·실행 해설·합성 CSV를 포함한다. 기존 22묶음의 집계와 별도로 관리한다.

생존분석의 기본 유형은 28회 응시자 후기에서 확인했으며, 세 집단 비교와 Cox 회귀 등은 응용·확장 학습으로 구분했다. 공식 시험 원문·배점·정답을 복제하거나 대체하는 자료가 아니다.

- [종합 모의5회](5회/README.md): 생산 의사결정14문항100점. ML40점·통계/최적화60점, 문제지·실행 풀이·코드·해설·고정 합성 CSV·독립 검증.

- [응용 종합 모의10회](응용10회/README.md): 회귀·분류·시계열·샘플링·튜닝을 연결한 신규10회150문항, 각100점. 문제지·실행 풀이·코드·해설·CSV·독립검증을 포함합니다.

## 도메인 배경 없이 시작하기

현재16묶음211문항에 자료안내.md·해설.md·분석코드.py를 함께 제공합니다. 각 문제지의 자료 이해 절에서 관측 단위와 변수 뜻을 먼저 확인하고, 수행 과제 → 실행 노트북 → 실제 수치 해설 순서로 학습하십시오. [공통 읽기 기준](../../docs/READABILITY.md)에 전체 구성과 재생성·검증법이 있습니다.
