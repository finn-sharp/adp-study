## 도메인 배경 없이 시작하기

데이터 분석을 전공했지만 해당 산업·업무는 처음 접하는 독자를 기준으로 구성했습니다.

1. **자료안내.md**에서 상황, 관측 단위, 변수 뜻·단위와 판단 목적을 확인합니다. 같은 `target` 이름도 대문항마다 의미가 다르므로 자료를 임의로 합치지 않습니다.
2. **문제지**에서 주어진 조건·배점·산출물을 확인하고, 분석 방법과 가설·평가 기준을 먼저 정합니다.
3. **풀이 노트북**을 위에서 아래로 실행합니다. 각 문항은 선택 근거 → 계산 → 핵심 표·그림 → 상황에 맞는 해석으로 이어집니다. `분석코드.py`는 같은 절차를 일반 Python에서 실행합니다.
4. **해설.md**에서 실제 수치와 판단을 대조합니다. 전체 정밀값·선택 경로·원행 기록은 `실행결과/답안수치.json`에 있습니다. 개선되지 않은 결과도 그대로 해석합니다.

## 분석 파이프라인과 설정·결과의 역할

`Dataset → 평가 설계·분리 → Feature 전처리·선택 → 학습 표본 처리 → Model·CV 튜닝 → 재적합·예측 → 예측 후 처리 → Metrics·진단·보고`

Recipe와 Profile은 각 단계의 실행 설정이고, DTO는 계산 후 결과를 전달하는 계약입니다. sampling은 모형 적합 전의 학습 자료 처리이며 예측 후 처리가 아닙니다. 변환·변수 선택·sampling·튜닝은 학습/CV 안에서 수행하고, 최종 평가 자료는 선택에 사용하지 않습니다. 상세 기능은 [저장소 README](../../README.md)와 [전체 분석 파이프라인](../../docs/ANALYSIS_PIPELINE.md)에 있습니다.

6~15회는 회귀36점·분류40점·시계열24점, 각15문항·100점·권장180분입니다. 공통 단계는 다음과 같습니다.

- 회귀: 기준 OLS → 계수 t·전체 F·R²/AIC/BIC → 선형성·잔차 정규성·등분산·독립성·VIF·Cook 진단 → 조건별 변환·선택·비선형/GLM 후보의 CV 비교 → 같은 원단위 보류 자료에서 ΔR²와 남은 한계 보고.
- 분류: 자연 발생률 자료 분리 → CV 학습 폴드 내부 sampling·GridSearchCV/Optuna → 별도 설명용 logit → ROC/AUC·AP·Brier·고정 임계값 비용.
- 시계열: 마지막 미래 구간 봉인 → 과거 rolling 검증으로 차수 선택 → AIC/BIC·잔차 진단 → 같은 미래에서 naive와 RMSE/MAE/R²/MASE·예측구간 비교.

VIF는 공선성, Cook은 관측 영향력을 다루며 결측 처리와 구분합니다. 높은 R²·AUC나 검정 비기각만으로 가정·인과·현장 성능을 확정하지 않습니다. [읽기 기준](../../docs/READABILITY.md)과 [출처·생성 가정](공통/응용_출처및설계.md)을 함께 참고하십시오.

## 6~15회 실행과 재생성

아래 명령은 저장소 루트에서 실행합니다. 표시 회차만 바뀌었으며 기존사례번호·데이터·시드·분할·후보는 유지합니다.

```bash
python -m pip install -r 기출문제/모의고사/공통/requirements-py312.txt
python tools/exams/run_applied_mocks.py
python tools/exams/audit_applied_mocks.py
# 단일 회차
python 기출문제/모의고사/6회/분석코드.py
# 문항·데이터·PDF 재생성 후 실행·검증을 다시 수행
python tools/exams/build_applied_mocks.py
```

실행 결과의 독립 계산 대조는 [6~15회 검증 결과](공통/응용_검증결과.json), 전체 자료의 구성·가독성 검사는 [전수 검증 결과](가독성_검증결과.json)에 기록합니다. 콘텐츠 실행 환경은 Python3.12이며 모듈의3.7/3.12 호환검사와 구분합니다.
