# 모의고사 20회 — 온도 지연값·전력 군집·비용 회귀

12문항·100점·권장240분. [자료 안내](자료안내.md) → [문제지](모의고사_20회_문제지.pdf) → [풀이](모의고사_20회_풀이.ipynb) → [수치 해설](해설.md) 순서로 학습합니다.

문항·배점·합성 자료·평가 조건은 창작이며 실제 기출 원문·정답·기업 데이터가 아닙니다. 회차 번호는 이 저장소의 모의 번호입니다. [10~20회 조사 및 대응표](../10~20회_출처조사.md)에 확인 범위·확장 조건을 기록했습니다.

| --- | --- |
| [R20·실제 기출20회](https://ysyblog.tistory.com/221) | 온도 지연값·RF/SVM 비교·전력 집계 군집/히트맵·회귀 |

각 대문항의 source_ids는 유형의 근거입니다. 출처 없는 연관규칙, PCA·Welch, 구간 설계·튜닝·시간 간격 등 구체 조건은 응용 확장입니다. 영어 품사는 제공된 통제 어휘 사전으로만 처리합니다.

저장소 루트에서 다음과 같이 실행합니다.

```bash
python -m pip install -r 기출문제/모의고사/공통/requirements-py312.txt
python 기출문제/모의고사/20회/분석코드.py
```

공통 코드는 `../공통/researched_*.py`에 분야별로 나누었으며 src의 기존 모듈을 조합합니다. 전체 정밀 수치·원행·확률·검증 구간은 실행결과/답안수치.json에 보존합니다.
