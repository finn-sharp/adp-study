독자 기준: 분석 전공 지식을 전제로 하되 도메인 배경은 아래에서 설명합니다. 수치는 실행 결과를 읽어 표시한 값이며 상세 정밀값은 실행결과의 JSON과 노트북 출력에 있습니다.

## 1. 회귀 설계와 조건별 개선

**상황을 이해하기**

발전 출력은 장비가 생산하는 전력의 크기이며, 경보는 점검이 필요한 사건 표시입니다.

**관측 단위와 판단 목적**

회귀 한 행은 독립 발전 관측, 분류 한 행은 별도의 사전 경보 관측입니다. 출력 예측과 사건 경보를 구분하고, 미래 일별 수요는 별도 자료로 예측합니다.

**변수 사전**

| 열 | 의미·역할 |
| --- | --- |
| `id` | 관측 식별자; 예측 입력에서 제외 |
| `target` | 출력(kW); 예측할 반응 |
| `irradiance` | 태양광 입사량의 편차 지수; 원 측정값/표본 표준화 아님 |
| `temperature` | 온도의 편차 지수; 원 측정값/표본 표준화 아님 |
| `voltage` | 전압의 편차 지수; 원 측정값/표본 표준화 아님 |
| `cloud` | 구름량의 편차 지수; 원 측정값/표본 표준화 아님 |

### 1-1

**수행 과제**

2. 지정 분할의 원행 위치를 남기고 전체 자료 대치나 식별자 입력이 왜 부적절한지 설명하시오.

**풀이 근거와 순서**

원행 위치를 먼저 봉인하고 결측 대치·스케일·선택은 Pipeline.fit 안에 둔다. id는 의미 없는 식별자이며 test는 최종 보고만 한다.
