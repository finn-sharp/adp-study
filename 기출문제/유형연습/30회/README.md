# 30회 후기 유형 연습

확인한 주제만 다루며 원 시험 전체 문항의 완전 복원이 아닙니다. 총 10문항입니다. 모든 데이터는 고정 합성 자료이며 실제 시험 자료가 아닙니다.

- 문제지: ADP_30회_유형_문제지.pdf
- 실행 해설: ADP_30회_유형_해설.ipynb
- 실행 코드: 분석코드.py (공통 계산은 ../공통/analysis.py)
- 해설: 해설.md, 문항명세.json, 실행결과/답안수치.json
- 자료: data/, 실행결과/, 실행검증.json

실행 환경·시드·검증·출처의 정정 사항은 상위 [안내](../README.md)와 [정제 명세](../출처_보완명세.md)를 확인하세요.

```bash
# 이 폴더에서 실행; 저장소 전체를 함께 내려받아야 합니다.
python 분석코드.py
```
