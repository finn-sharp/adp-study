# 30~36회 후기 유형 연습

공개 응시 후기에서 확인한 주제를 바탕으로 정제한 **7묶음·53문항**이다. 기존 공문서형 A4 문제지, 별도 실행 해설 노트북, 실행 Python 코드, 설명 Markdown, 합성 데이터, 실제 수치 답안과 검증 기록을 함께 제공한다. 공식 원문이나 실제 데이터의 완전 복원이 아니며 문항 번호·수치·조건·모형 후보·분할·시드와 예측 가용성을 새로 명시했다. 실제 시험 배점을 복제하지 않았다.

확보된 주제와 채택하지 않은 잘못된 해설, 회차 혼동은 [출처·보완 명세](출처_보완명세.md)에 정리했다. 원 글의 문장·이미지·데이터를 복제하지 않고 유형만 참고했다. 미확인 37회 이후 문항은 추가하지 않았다. 기존 22묶음 및 생존분석 모의와 집계가 다르며, 해설 파일은 별도 확장 검사에서 관리한다.

## 실행 파일 구조

회차별 `ADP_XX회_유형_문제지.pdf` / `ADP_XX회_유형_해설.ipynb` / `분석코드.py` / `해설.md` / `문항명세.json` / `data/` / `실행결과/답안수치.json` / `실행검증.json`을 제공한다. `공통/analysis.py`는 모든 계산의 실제 구현이다. 노트북과 독립 코드 모두 그 구현을 실행하며 의사코드가 아니다. 설명형 답안은 해설 셀/Markdown, 가설·실제 계산·판정은 해당 question ID의 JSON/실행 출력에 있다. 그림·정제 CSV도 실행결과에 저장한다.

```bash
# 저장소 루트, 별도 Python 3.12 환경 권장
python -m pip install -r 기출문제/유형연습/requirements-py312.txt
python tools/exams/run_recent_exams.py
python tools/exams/audit_recent_exams.py
# 또는 회차 폴더에서 python 분석코드.py
# 지문·자료·PDF·미실행 해설 재생성(출력 초기화)
python tools/exams/build_recent_exams.py
# 재생성 후 위 실행·검사를 다시 수행한다.
```

실행 환경은 Python 3.12.14이다. 작성 코드의 Python 3.7 구문은 검사하나 최신 sklearn·SciPy API 등으로 인해 이 확장 묶음의 Python 3.7 런타임 호환을 주장하지 않는다. 기존 3.7 분석 모듈 의존성은 변경하지 않는다. 실행 버전은 requirements-py312.txt와 실행검증.json을 확인한다.

## 합성 자료·정답 규약

- 회차별 `RandomState(20261000 + 회차)`를 한 번 사용한다. 생성을 위한 모수는 `tools/exams/recent_exam_data.py`, CSV별 행·열·출처는 데이터명세.json에 기록했다. p값을 맞추기 위한 사후 표본 재선택은 하지 않는다.
- 원 데이터가 없으므로 실제 시험 성능·검정 결론을 재현했다는 의미가 없다. 추론 문항은 독립성·정규 평균모형 등의 작업 가정을 지문/풀이에 명시한다.
- 34회는 같은 학생이 3개 학습법을 모두 경험한 균형 mixed 설계다. 학생 내 공분산의 구형성을 가정하지 않고 GG 보정을 적용한다. 원 글의 일반 Tukey 해석을 대응 비교+Holm으로 교정했다.
- ML의 전처리·표본 보완은 CV 학습 폴드 안에서만 적합한다. 모형 선택은 내부 CV, 최종 시험은 선택 완료 후 평가한다. 시간 자료에는 시간순 분할과 CV를 적용한다. 미보고 고정 기준 모형의 내부 적합은 성능 주장이 아니다.
- OOF 특성은 자기 행의 타깃을 보지 않는 예측값이다. 단, 선택된 변수를 고정해 만드는 OOF는 변수 선택까지 완전 중첩한 성능 추정이 아님을 밝힌다. 후속 분류의 독립 시험은 끝까지 보류한다.
- 유의성 검정의 비기각을 동일성·정규성의 증명으로 적지 않는다. 평균·위치·분포·오즈비·인과 효과를 구분한다. 기술통계·확률 계산·수송 최적화에는 불필요한 p-value를 붙이지 않는다.
