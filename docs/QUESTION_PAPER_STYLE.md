# 문제지 공통 서식

공문서의 절제된 흑백 구성과 문서 계층을 참고한 학습용 서식입니다. 정부기관의 문서·공식 시험지로 표시하지 않으며 모든 쪽에 학습용 복원 자료임을 명시합니다.

- A4 세로, 좌우 20mm 여백, 본문 상하 24mm. 나눔고딕 임베딩.
- 중앙 제목 21pt, 본문·문항 11pt/행간 19pt, 자료 조건·출처 9pt.
- 첫 쪽에 회차·문항 수·성명·작성일·응시 안내·자료 출처를 배치합니다.
- 대문항은 옅은 회색 바탕과 흑백 구분선, 세부 문항은 기존 식별자와 내어쓰기를 사용합니다.
- 표는 같은 폭과 가는 구분선을 사용하며, 원문 제시 그림과 수치 표를 보존합니다. 원문 그림의 색상은 유지합니다.
- 짧은 분석 과제는 묶어 배치하고, 긴 과제는 문항 단위로 넘깁니다. 자료 조건·표와 첫 문항을 함께 배치해 제목만 남는 페이지를 방지합니다.
- 회차별 머리말과 가운데 쪽번호를 통일합니다. 데이터 미제공·합성 자료 여부는 기존 출처 명세대로 표시합니다.

## 재생성

`python tools/exams/render_question_papers.py`는 기존 `문항목록.json`과 `추가_문항명세.json`에서 문제지 22개만 다시 생성합니다. 풀이 노트북과 데이터는 수정하지 않습니다. `--folder 18회` 등으로 회차를 선택할 수 있습니다. ReportLab이 필요합니다.

`build_reconstructions.py`도 같은 렌더러를 사용하므로 다음 복원 빌드에서 이전 서식으로 돌아가지 않습니다.

## 검증

162문항의 전체 지문, 기존 제시 조건·수치 표의 PDF 텍스트 보존, 그림 포함 여부, A4 페이지와 본문 경계를 확인했습니다. 전체 페이지를 이미지로 렌더링해 줄바꿈·표·페이지 전환을 검수했습니다. 풀이·데이터·문항 명세의 바이트는 이전 버전과 같습니다. 기존 실행 검증 결과는 유지하고 문제지의 페이지 수와 SHA-256만 갱신합니다.
