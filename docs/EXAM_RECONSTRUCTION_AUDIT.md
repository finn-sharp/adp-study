## 자료 간 차이와 통계적 교정

- 18회 SOM의 격자 좌표는 고객등급이 아닙니다. 학습 라벨의 격자별 빈도와 전체 prior로 예측 확률을 구성하며, 검증 라벨로 격자를 매핑하지 않습니다. 이는 비지도 SOM 위에 추가한 지도 판별 절차입니다.
- 19회 후기의 정규성/정상성 혼용을 구분합니다. ADF는 단위근 검정, Shapiro는 정규성, 시간별 분산 변화는 이분산, Ljung-Box는 자기상관 진단입니다.
- 20회 후기는 가구×일자의 총 전력량 군집을 제안하지만 DataManim 예시에는 같은 가구의 레코드가 다른 군집으로 나타납니다. 기존 20회 풀이에서는 15분 관측 수준 군집 해석을 명시했습니다. 둘은 동등한 군집 단위가 아니므로 원 시험 조건을 단정하지 않습니다.
- 20회 날씨 후기의 랜덤 분할·MAPE 예측값 분모 제안은 미래 예측 목적에 맞게 시간순 분할 및 실제값 분모로 교정합니다. 섭씨 0 부근의 MAPE는 불안정하여 RMSE·MAE를 우선합니다. RBF SVR에는 coef_가 없으므로 permutation importance를 사용합니다.
- 22회 분산 기준 검정은 ANOVA의 평균 검정과 다릅니다. 표본 분산의 χ² 검정, 제조사 평균 비교, 관리도를 혼용하지 않습니다. 생산량 기대값은 확률 생성 규칙이 있어야 정의됩니다.
- 23회 부호검정은 동률을 제외한 양/음 개수로 수행하며 signed-rank 순위 통계량과 구분합니다. 누적 확진자의 미보고 결측을 실제 0으로 단정하지 않습니다.
- 이원 ANOVA의 두 번째 범주가 없는 21회 요약은 x의 고정 기준 범주를 연습용으로 보완합니다. 원문이 ANCOVA였을 가능성은 남깁니다.
- 한국어·영문 텍스트의 동봉 POS 사전은 합성 자료 전용입니다. 임의 토큰을 실제 형태소 분석 결과라고 표시하지 않습니다.

## 재생성과 실행

저장소 루트에서 `python tools/exams/generate_fixtures.py`, `python tools/exams/build_reconstructions.py` 순서로 실행하면 합성 CSV와 추가 문제지·노트북을 재생성합니다. 생성기는 코드가 같으면 기존 실행 출력을 보존합니다. 독립 실행은 `python tools/exams/execute_notebooks.py <풀이.ipynb>`입니다. DataManim 원자료와 기존 5개 문제지는 별도 보존합니다.

실행 기록은 회차별 `실행검증.json`과 전체 `검증결과.json`에 있습니다. Python 3.7은 문법 및 의존성 명세를 점검하고 CI matrix에서 모듈 테스트를 수행하도록 구성합니다. 복원 노트북의 실제 실행 환경은 Python 3.12입니다.
