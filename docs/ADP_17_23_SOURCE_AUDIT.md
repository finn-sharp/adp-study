## 가정과 한계

- 원자료가 없는 회차는 합성 연습 자료입니다. 원 시험 수치·성능을 재현했다고 주장하지 않습니다. 18회 합성 등급은 구매당 금액의 분위수로 생성돼 파생변수와 강하게 연결되므로 실제 고객 예측 성능 근거가 아닙니다.
- SOM 격자 번호는 고객등급이 아닙니다. 학습 표본의 격자별 라벨 빈도와 학습 prior로 확률을 매핑하며 validation/test 라벨은 사용하지 않습니다.
- 영어 POS 사전은 합성 문서에만 적용합니다. 실제 원문은 설치된 형태소/POS 모델의 분석 결과와 버전을 별도로 기록해야 합니다.
- 정상성, 정규성, 이분산, 잔차 자기상관을 분리해 해석합니다. 계절 나이브 등 추가 기준선과 운영 자료 검증은 별도 과제입니다.
- 튜닝으로 점수가 반드시 개선되는 것은 아닙니다. train CV 최고점과 validation 선정, 최종 test 지표를 각각 표시합니다.

## 재현·검증

`tools/exams/build_reconstructions.py`가 문제지·풀이와 출처·보완 조건 명세를 생성합니다. `tools/exams/audit_package.py --execute`는 회차별 독립 프로세스 실제 실행, 노트북 스키마·출력 오류·Python 3.7 구문·원자료 해시·PDF 텍스트 경계·문항 누락을 검사합니다. 최종 결과는 `기출문제/검증결과.json`과 회차별 `실행검증.json`에 기록했습니다. 실제 실행은 Python 3.12이며 Python 3.7 런타임은 GitHub CI의 분석 모듈 matrix에서 확인하도록 구성했습니다.
