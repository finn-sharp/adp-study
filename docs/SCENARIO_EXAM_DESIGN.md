# 기출·모의 상황형 재구성

## 적용 범위와 원문 구분

기출·모의·보충 22묶음 162문항의 응시자용 지문과 풀이를 변경했다. 원문을 그대로 복원했다는 의미가 아니라, 제공 자료의 분석 주제·데이터·계산 조건을 활용한 상황형 재구성이다. 기존 `문항목록.json`, `추가_문항명세.json`, `mock_source_questions.json`은 원문·기존 복원 명세로 보존한다. 새 문제·원문 대응·풀이 근거는 `기출문제/상황형_문항명세.json`에 문항 ID별로 기록한다. 원 데이터·합성 연습 데이터의 구분과 데이터 바이트는 유지한다.

## 출제 계약

- 문항은 업무 목적·관측 단위·변수 척도·표본 설계·의사결정을 제시한다. 방법의 이름만 지정해 실행하도록 하는 형태를 줄였다.
- 같은 분석을 잇는 전처리·모형 비교 문항은 동일 자료·행·전처리 기준·학습/검증/시험 구간을 공유한다. 별도 과제는 별도 자료임을 밝힌다.
- 모든 회차를 억지로 동일한 데이터셋 개수로 바꾸지는 않는다. 22·23회처럼 기계학습 1~3번이 이어지는 구조, 26회의 1·2번 공유 구조 등 회차별 분석 맥락을 유지한다. 본편·후기보충의 서로 다른 복원 가정도 유지한다.
- 통계 문항은 독립/대응 여부, 연속/범주 척도, 평균/분산/비율/분포/순서의 비교 목적을 응시자가 읽고 검정 방법을 고르게 한다. 정답 검정명은 응시자용 제목·상황·질문에 직접 쓰지 않는다. 출처의 주제 나열에 있던 정답명도 문제지에서는 제외했다.
- 검정 문항은 방법과 선정 근거 → 필요한 가정 → 귀무·대립가설과 방향 → 통계량·자유도·p-value → 유의수준과 기각 여부 → 상황의 결론을 요구한다. 여러 효과·진단은 가설을 분리한다.
- 확률 계산·신뢰구간·관리도·군집·생존함수 추정에는 목적과 무관한 귀무가설이나 p-value를 억지로 요구하지 않는다.

## 풀이 계약

노트북의 문제 지문은 PDF·상황형 명세와 같다. 기존 계산과 도표를 유지하면서 선택 근거·가설·실행 수치·결론을 보강했다. `공통/scenario_inference.py`는 실제 계산한 통계량과 p값을 보고하며 각 회차 `실행결과/가설검정_답안.json`에 가설·방법·가정·수치·기각 여부·결론을 기록한다. 검정이 없는 묶음은 빈 배열이다.

- 기각하지 못함은 귀무가설의 참 또는 두 모집단 동일성의 증명이 아니다.
- 감소/증가 단측 가설은 차이·기울기 방향과 일치시킨다. 양측과 보조 단측 결과를 사후 선택하지 않는다.
- 독립 두 평균에는 모분산을 모를 때 Welch, 같은 대상 전후에는 차이의 대응 검정, 대응 이진 응답에는 불일치 셀 기반 정확 검정을 사용한다.
- 한 표본 분산 검정은 정규 모집단 가정, 순위 비교는 독립성·동률·분포 형태의 한계를 밝힌다. 분포 차이를 자동으로 중앙값 차이라고 쓰지 않는다.
- 다중 상관·요일 평균 비교는 Holm 보정 p값으로 기각 여부를 보고한다. 시계열 의존성이 있는 관측의 독립 검정 p값은 탐색적 작업 가정임을 명시한다.
- 요인 모형의 주효과와 상호작용, 잔차의 정규성과 자기상관은 별도 가설이다. Ljung-Box 자유도는 실제 선택된 비계절·계절 AR/MA 계수 수를 차감한다.
- 설명 회귀·상관·시식 전후의 연관을 인과 효과로 단정하지 않는다. 변수 선택 후 추론과 작은 표본의 한계도 보고한다.

## 재생성과 검사

```bash
# 기존 자료에서 상황형 PDF·풀이·대응 명세를 갱신한다.
python tools/exams/apply_scenario_style.py
# 모든 풀이를 독립 프로세스로 실제 실행하고 기존 패키지 검사도 수행한다.
python tools/exams/audit_package.py --execute
# 문항-PDF-풀이 지문, 검정명 노출, 가설 보고 누락·기각 계산을 검사한다.
python tools/exams/audit_scenarios.py
```

`build_reconstructions.py`도 마지막에 상황형 변환을 호출한다. `render_question_papers.py` 단독 실행은 상황형 명세를 우선 사용한다. 변환을 다시 실행해도 셀에 코드를 중복으로 붙이지 않으며 코드가 같으면 실행 출력을 보존한다. 원 코드·해설은 셀 metadata에 보존한다. Python 3.7 구문을 유지하며 실제 노트북 실행 검증은 Python 3.12 환경이다.
